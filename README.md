# Project README content

The following README content identifies the team and documents the completed project and workflow.

## Project Description

Student Task Manager is a browser-based application for adding, displaying, completing, deleting and searching tasks.

## Team Members

- Muhammad Ibtsam ul haq — MSDSF26M008 — @ibtsam7550
- Maham Asif — PHDDSF26M004 — @maham-1792

## Features

Task title and description entry; task display; completion and deletion controls; case-insensitive title search; styled form and task cards.

## Technologies

HTML, CSS, JavaScript, Git and GitHub.

## Git Workflow

Create a feature branch, edit files, stage and commit changes, push the branch, open a pull request, review the changes and merge into main. Synchronize local branches before continuing.

## Branches

main, feature/task-form, feature/task-style, feature/task-search and conflict-student2.

## Git Commands Demonstrated

init, status, add, commit, log, branch, switch, diff, diff --staged, clone, remote -v, push, fetch, pull (attempt), merge, stash, restore, reset --soft, revert and tag.

## GitHub Features Demonstrated

Public repository, issues, pull requests, review of PR #4, PR conversations, merges, issue closure, tag, release and contributions.

## How to Run

Clone [https://github.com/ibtsam7550/student-task-manager.git](https://github.com/ibtsam7550/student-task-manager.git) and open index.html in a web browser. Enter a task title and optional description, then select Add Task. Use the search field to filter titles and the task controls to complete or delete an entry.
